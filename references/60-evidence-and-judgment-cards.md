# 60 — 證據卡、假設卡與行動卡

**reason**：把「我看到什麼」「我因此推測什麼」與「下一步要做什麼」分開，讓初學者可以回看、挑戰與重做每個 SEO 判斷。
**strip_when**：若教學不再需要保存判斷依據、限制與下一個可驗證動作，才移除；一般概念快問快答不必建立完整卡片。

這是跨模組的判斷格式，不是評分表，也不取代 G0–G7、G3 實驗室或 A1–A4 作品集。進入實際診斷、策略選擇或修改前，至少留下最小的一張證據卡；資料很少時可以只填已知欄位。

## 證據卡：先記觀察，再說限制

```markdown
### 證據卡 E-[編號]
- 範圍：網站／URL／查詢／期間／地區／裝置
- 來源：官方文件／公開頁面／無痕 SERP／學員截圖／GSC 或 GA4／工具估值
- 查核日：YYYY-MM-DD
- 實際觀察：只寫本輪真的看到或收到的內容
- 可以支持：這筆證據能支持的最小敘述
- 不能支持：尚不能由它推出的結論
- 證據標籤：[官方行為 / 公開觀察 / 第三方估值 / 學員證據 / 教學判斷]
- 狀態：[confirmed / likely / hypothesis / unknown]
- 下一個區分檢查：只寫一個能縮小不確定性的檢查
```

固定規則：

- `unknown` 不是失敗；代表目前沒有足夠資料。
- `candidate` 不是 `verified`；候選機會、候選缺口與候選重寫都要先保留條件。
- 一筆工具數字只能支持它的定義範圍；第三方估值不能變成搜尋引擎內部事實。
- 「沒有看到」只能寫成未觀察或查核範圍內未發現，不寫成全站不存在。
- 前後期、不同頁面或不同裝置不能混成同一個結論；先寫清楚範圍再比較。
- 學員貼上 GSC 面板「複製證據卡」的文字（或教練用 CLI 讀到的輸出）時，它已填好範圍、來源、查核日與觀察，直接當這張卡的觀察半邊，不再要求重截同一個畫面；暫定解釋、推翻條件與「下一個區分檢查」仍由學員與教練寫。

## 假設卡：讓判斷可以被推翻

當證據仍不足但必須決定下一個學習步驟時，另留一張假設卡：

```markdown
### 假設卡 H-[編號]
- 目前問題：用戶想改善什麼可觀察結果
- 暫定解釋：一句話，不寫成已證實根因
- 依據：連回一張或多張證據卡
- 讀者／搜尋任務是否吻合：是／否／待查
- 現有頁面是否適合承接：是／否／待查
- 網站是否能可信提供答案：是／否／待查
- 風險：錯判後最可能造成什麼浪費或傷害
- 推翻條件：看到什麼就停止這個假設
- 下一個檢查：一項、可在本輪或下一輪完成的檢查
```

教練要把「為什麼現在先查這個」說成教學判斷，而不是把假設包裝成 Google 規則。若推翻條件已出現，就把狀態改成 `rejected`，保留原卡，不覆蓋成看似正確的故事。

## 行動卡：一次只做一個可回復動作

```markdown
### 行動卡 A-[編號]
- 對應假設：H-[編號]
- 修改前基準：數值／頁面狀態／截圖／日期
- 唯一動作：一個低風險、可回復的修改或觀察
- 完成條件：現場能檢查的技術或內容條件
- 觀察窗口：何時回看、看哪個同定義指標
- 回復方式：如何還原原狀
- 結果：[未做 / 已完成待重驗 / 已重驗 / 延長觀察 / 回復 / 未定]
```

不要把「改了 title」直接寫成「排名會上升」，也不要把面板列出的候選當成自動行動。每張行動卡只連一個主要假設；如果同時需要改 URL、內容與技術設定，拆成多輪並重新留基準。

## 教學使用順序

1. 先示範一張最小證據卡，指出觀察與不能推出的結論。
2. 讓學員填下一張同型卡；卡住時只補一個欄位或一個選項。
3. 形成假設後，請學員說出一個推翻條件。
4. 由學員提出行動卡；教練只檢查範圍、風險、完成條件與回復方式。
5. 重驗後更新狀態，不刪除原始觀察與原始假設。

不需要每次把整張模板貼給新手。第一輪只露出「來源、觀察、不能證明、下一個檢查」四欄；學員能穩定分開觀察與推論後，才加入完整卡片。
