# 54 — 四篇 SEO 寫作學徒軌道

**reason**：把關鍵字、搜尋意圖、內容規劃、寫作、修改、發布與觀察串成四篇可驗收作品，讓學員不是只聽懂，而是能在換題後獨立完成。
**strip_when**：若主技能不再提供長期寫作陪跑，或官方搜尋品質原則與公開課程已無法支撐本軌道的基礎判準，就停用並重新設計。

這是一條可選的實作軌道，不取代 G0–G7 真站主線。學員必須親手寫、判斷並保留證據；教練可以示範、共同做 brief、逐段回饋與指出修改方向，但不能直接交付整篇可發布成品。

## 四篇的難度梯

| 作品 | 教練角色 | 學員必須證明 | 通過方式 |
|---|---|---|---|
| A1 示範共作 | 示範研究與一小段寫法，和學員共同完成 brief | 能說明查詢、意圖、頁型與每個必要段落的用途 | 全程可提示；學員完成主要草稿與真實證據 |
| A2 同型實作 | 只在卡住時提示，逐輪審稿 | 能把 A1 流程換到另一個同型題目 | 至少一次只靠輕提示完成研究到 QA |
| A3 變式遷移 | 不先給答案，只指出證據缺口 | 能處理不同搜尋意圖與不同頁型 | 不沿用前兩篇模板；意圖與頁型判斷正確 |
| A4 無提示 Capstone | 只給商業目標與可用網站，不提示工具或步驟 | 能自行選查詢、收證據、做 brief、寫稿、修訂、QA、發布與設計觀察 | 八個硬門檻全過；7 天後換題口頭重建流程仍正確 |

同一篇重寫四次不能算四篇。A3 必須換搜尋意圖或頁型；A4 必須是未共同做過的新題。

A4 學員索取完整步驟、工具或答案時，拒絕提示後必須明說：提交物仍會依 **W1–W8** 驗收。不能只說「我會逐項看」而不指出既定硬門檻；也不能為了安撫而先洩漏順序。

## 每篇固定留下的證據鏈

依序完成；缺一項就停在該階段，不用分數補過：

1. **商業目標**：這篇服務誰，閱讀後希望他完成什麼合理下一步。
2. **關鍵字證據**：目標查詢、來源、查核日期、第三方估值標籤及放棄條件。
3. **SERP 意圖**：地區／語言／日期、前排頁型與格式、混合或不確定處。
4. **Content brief**：先判 `new / improve`；再記讀者任務、必要問題、可省略項、自己的真實證據、標題方向、H2／H3、真實內鏈候選。`improve` 額外留下 `保留／加強／新增`，不預設整篇重寫。
5. **初稿**：保留原始版本，不覆蓋。
6. **教練回饋**：每條回饋都指向一個硬門檻與具體段落；不直接整篇重寫。
7. **修改稿**：記錄接受、拒絕或改寫了哪些建議及理由。
8. **On-page QA**：title、H1、段落層級、內鏈、圖片文字替代、可讀性與基本事實查核。
9. **發布／留底**：發布 URL、日期、最終稿或 CMS 留底、索引檢查日期。
10. **後續觀察**：觀察窗口、GSC／GA4 指標、結果與下一個決定。初次可用 28 天作檢查點；搜尋量或重爬不足時延長，不把沒變化硬判為失敗。

沒有付費工具時，SERP 研究照 `55-search-opportunity-lab.md` 手動完成：開新的無痕／私人視窗，確認地區與語言，記錄裝置與日期。A1 第一輪由教練只示範第 1 個自然結果，後續輪才共做第 2 個、由學員判讀第 3 個；三筆已一致就停，混合意圖才多看 2 筆。每輪保留截圖，教練不代填完整表。

## 八個硬門檻

每項只記 `pass / revise / not-assessable`。`not-assessable` 不能當 pass；補到能判斷再結案。AI 分數、外掛綠燈、字數與關鍵字密度都不能取代硬門檻。

| Gate | Pass 證據 | 常見退回原因 |
|---|---|---|
| W1 意圖與頁型 | SERP 證據支持文章／指南／比較等選擇，且能完成搜尋者任務 | 用文章硬接交易型或導航型需求 |
| W2 事實與來源 | 可查事實有來源；經驗、案例、測試確實屬於學員 | 虛構數字、經驗、引言或來源 |
| W3 必要問題 | 回答會影響理解或決策的必要問題，沒有只為湊長度的段落 | 漏掉核心疑慮，或大量離題 |
| W4 原始價值 | 至少有一項學員自己的經驗、資料、產品資訊、流程或觀察 | 只是改寫前三名，沒有自己的材料 |
| W5 結構與 On-page | title、H1、H2／H3、段落與內鏈服務讀者，沒有互相矛盾 | 標題不符內容、層級混亂、硬塞內鏈 |
| W6 可讀性 | 目標讀者能順著問題取得答案；術語有必要解釋 | 空話、重複、長句或模板腔妨礙理解 |
| W7 無關鍵字堆疊 | 用詞自然；刪掉重複關鍵字後意思不受損 | 固定密度、同義詞清單或機械重複 |
| W8 紀錄完整 | brief、兩版稿、回饋、QA、發布與觀察證據可回看 | 只剩最終稿，無法證明判斷與修改過程 |

## 每輪陪跑規則

- 一輪只推進一個階段或修一個主要 Gate；不要一次把整篇問題全部倒給新手。
- 先指出證據與影響，再請學員改；學員說「示範」時，只示範一小段或一種改法，下一個同型段落交還學員。
- 回饋用「段落位置 → 問題 → 為何影響讀者／意圖 → 修改任務」格式，不用籠統的「內容不夠深入」。
- 競品只用來辨認必要問題、頁型與讀者期待；不得逐段仿寫、換句話說或把競品經驗寫成學員經驗。
- 內容涉及健康、財務、法律或安全時，先確認學員是否有資格與可靠來源；不足就縮小題目或找合格審稿者。
- 發布後不承諾排名。用相同定義的資料回看，最後只做「保留／修正／延長觀察／換假設」決定。

## 作品集畢業

四篇都達到 W1–W8 `pass`、都有可讀取的發布或留底證據，且每篇完成至少一次預定觀察，才可說「完成四篇 SEO 寫作作品」。A4 必須無提示通過，並在至少 7 天後換題重建一次流程，才可把寫作能力標為 `retained`。

不能用以下項目替代畢業證據：

- AI 或 SEO 外掛總分。
- 「已經寫了四篇」的口頭宣稱。
- 四篇同模板、只換關鍵字的內容。
- 教練代寫後由學員按發布。
- 排名、流量或收錄保證。
