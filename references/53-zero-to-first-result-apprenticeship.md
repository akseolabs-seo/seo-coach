# 53 — SEO Apprenticeship：從零到第一個可驗證成果

18 個模組是按需查閱的知識庫，不是畢業條件。主線是一個學員親手完成的真站閉環。

## 八個 Gate

| Gate | 學員要完成 | 合格證據 |
|---|---|---|
| G0 目標與安全 | 一個真站、一個業務目標、一個有權控制的頁面 | 一句話專案目標與權限邊界 |
| G1 修改前基準 | 寫齊目標、主要指標、資料來源、比較期間、修改前數值／狀態 | 可重複讀取的 baseline；缺一不進 G4 |
| G2 Google 看得到 | 分清可存取、爬取、索引、曝光 | URL／GSC 證據及它不能證明什麼 |
| G3 找一個機會 | 逐步完成候選查詢、無痕 SERP 意圖、相對缺口、承接頁／架構與 brief | 「查詢→頁面→問題」假設及一格一格累積的證據鏈 |
| G4 一項實作 | title／H1、內容段落、內鏈或明顯資訊缺口之一 | 修改前留底、上線變更與日期 |
| G5 技術重驗 | 確認變更真的出現在真實頁面且沒破壞基本狀態 | 修改後 HTML／畫面／GSC 證據 |
| G6 結果判讀 | 到預定窗口比較相同定義，考慮替代解釋 | 保留／回復／再測的決定 |
| G7 Capstone | 換陌生頁面無提示跑縮小閉環 | 通過 rubric 並於 7 天後換案例複測 |

每個 Gate 可分多輪；每輪仍只教一個概念、做一個檢查。沒有 G1 不進 G4；沒有 G5 不宣稱修改完成。

## G3 搜尋機會實驗室

G3 不在一輪內完成，也不要求付費工具。依 `55-search-opportunity-lab.md` 自主帶學員逐格前進：

| 小格 | 本輪只完成 | 最小合格證據 |
|---|---|---|
| G3a 候選查詢 | 從一個真實問題找一個候選 | 原句／來源／日期／受眾與業務關聯 |
| G3b SERP 意圖 | 開無痕視窗，先看一個、最多三個自然結果 | 查詢、地區、語言、裝置、日期、截圖、頁型；未看到的標未觀察 |
| G3c 相對缺口 | 比自站一頁與一個合理競品的一個問題 | `candidate / verified / 不值得補 / 待查` 及雙邊 URL 證據 |
| G3d 承接頁／架構 | 決定改善既有頁、新建或暫不做 | `new / improve / 待查`、頁面任務與 URL 風險 |
| G3e 一頁式 brief | 只規劃完成讀者任務所需內容 | 必要問題、本站真實材料、段落用途、真實內鏈與放棄條件 |

完全新手從 G3a 或 G3b 的 L0 指路開始；教練示範一格後才共做下一格。若三個結果已一致就停；只有混合意圖才在下一輪再多看兩個。沒有找到值得補的缺口、決定沿用既有頁面或標記證據不足，都是合格結果。

G1 可以分輪收資料，但在進入 G4 前必須把五欄逐一展示給學員確認；若第一輪只先要 URL，也要明說後續還會記主要指標、資料來源、比較期間與修改前數值／狀態。

「第一個成果」不強迫一定流量上升。以下任一項可算：

- 建立正確而可重複的基準。
- 找到並安全修復可驗證問題。
- Google 重新處理或開始出現相關搜尋訊號。
- 實驗結果支持保留、回復或再測的決策。

只有上課、完成練習題、教練代做或沒有 baseline 的前後比較都不算。

## 可選作品軌道

學員的主要目標是內容寫作時，G0–G7 仍負責目標、基準、發布驗證與結果判讀；作品產出另走 `54-four-article-writing-apprenticeship.md` 的 A1–A4。完成一篇不能取代四篇梯度，四篇也不能取代 G7 的延遲遷移證據。

## 能力狀態

每項能力只用：

- `unseen`
- `demonstrated`
- `guided`
- `independent`
- `retained`

`guided → independent`：不同案例至少兩次正確，其中一次無提示。  
`independent → retained`：至少 7 天後換案例仍正確。  
出錯只調整該能力，不把整個學員降級。

每次記錄：能力 ID、提示級別 0–3、案例、學員做了什麼、錯誤類型、證據、日期、下次 1／7／30 天複測日。

## 練習梯

1. 示範題。
2. 同型共做題。
3. 換 URL 的近遷移題。
4. 有例外的變式題。
5. 要自己選檢查的混合題。
6. 自己網站。
7. 1／7／30 天無提示複測。

一次答對不能標記「會了」。練習網站只使用公開資訊；不能把第三方網站當成私有 audit 對象。

## Capstone

題目只給：

> 這個頁面想增加自然搜尋帶來的有效詢問。請說你先查什麼、看到什麼、先做哪一項，以及怎麼確認有效。

| 項目 | 權重 |
|---|---:|
| 目標與範圍 | 15 |
| 證據選擇與邊界 | 25 |
| 假設品質 | 15 |
| 優先級與低風險行動 | 20 |
| 修改後驗證 | 15 |
| 知道何時升級專業 | 10 |

安全、授權、證據邊界三項為硬門檻；總分至少 80，教練不得提示工具。7 天後用另一頁仍通過，才標記 `retained`／可獨立做基礎 SEO。
