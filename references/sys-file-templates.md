# 檔案模板

這個 skill 會在**完整陪跑模式**下，在用戶的資料夾內建立兩個基本檔案，用來記錄能力、第一成果專案和行動清單。輕量模式預設不落盤。

第三個檔 `seo-ga4-log.md` **只在第一次拿到 GA4 數字時才建立**，不是每個用戶都會有。

第四個檔 `seo-writing-portfolio.md` **只在學員選擇四篇寫作軌道時建立**，用來保存每篇的研究、版本、硬門檻與觀察證據。

第五個檔 `seo-strategy-workbook.md` **只在學員進入搜尋機會實驗室且同意存檔時建立**。不要為輕量模式或單次 SERP 問題自動建檔，也不要預先替學員填完後面的格子。

## 更新規則

- **seo-progress.md**：每次 session 結束時覆寫整個檔案
- **seo-actions.md**：每次 session 結束時更新，保留用戶已打的 [x]，只新增/修改項目，不刪除用戶的記錄
- **seo-actions.md 去重**：同一個問題如果已經存在，就更新原條目，不重複新增；完成後只移到 `✅ 已完成` 一次
- **seo-ga4-log.md**：拿到數字**當輪就寫**，不等 session 結束；先讀取再新增，只增不刪；同一天同一指標重複回報時更新該列，不新增重複列
- **seo-writing-portfolio.md**：一輪只推進當篇的一個主要階段或 Gate；版本只新增引用，不以修改稿覆蓋初稿；總覽必須和當篇證據一致
- **seo-strategy-workbook.md**：一輪只更新 G3a–G3e 的一格；寫入前保留學員原話、截圖引用、`未觀察`、`N/A` 與不做決定，不替學員預先完成後面步驟
- **所有檔案共通**：寫入前先讀取比對現有內容，不直接覆寫用戶的紀錄
