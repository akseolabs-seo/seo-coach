# SEO 成效衡量（Measuring SEO / Showing Value）

## 核心概念
SEO 的時間線依爬取、競爭、網站歷史與改動類型而變，沒有保證的 3–6 個月公式。因此，先記錄改了什麼、看同一指標的趨勢，比等待排名第一更重要。

---

## 關鍵 SEO 指標

### 1. 自然搜尋流量（Organic Traffic）
最直接的 SEO 成果指標。

**怎麼看：**
- Google Analytics 4（GA4）→ 報表 → 客戶開發／獲取（Acquisition）→ 流量開發／流量獲取（Traffic acquisition）→ 篩選「自然搜尋」（選單字樣依版本與語言而異；帶新手看這張報表 → `50-ga4-coaching-track.md` L2 指路卡）
- GSC → 成效 → 搜尋結果 → 點擊數

**注意：**
- 流量本身不等於商業價值，要看流量的質量（有沒有轉換）
- 季節性因素：某些行業有明顯的淡旺季

---

### 2. 關鍵字排名
你的目標關鍵字目前排在第幾位。

**怎麼看：**
- GSC → 成效 → 平均排名（注意：是所有關鍵字的平均，意義有限）
- GSC → 成效 → 查詢 → 看特定關鍵字的排名

**排名的現實：**
- 排名因用戶位置、搜尋歷史而異，沒有絕對固定的數字
- 不用固定 CTR 曲線判好壞；廣告、地圖、AI features、品牌字與查詢意圖都會改變點擊分布

---

### 3. 點擊率（CTR）
在搜尋結果中曝光後，有多少比例的人點擊你的連結。

**怎麼看：**
- GSC → 成效 → 點擊率

**CTR 的意義：**
- 判斷 CTR 時，比較同站內「查詢意圖與排名相近」的頁面；低 CTR 可能是 title、意圖、SERP feature 或品牌需求差異
- CTR 提升 = 不用排名上升就能增加流量

---

### 4. 曝光數（Impressions）
你的頁面出現在搜尋結果的次數（不管有沒有被點擊）。

**用途：**
- 曝光多但點擊少 → 先分 title／意圖／SERP feature／頁面類型，不直接假定只要改 meta
- 曝光少 → 排名問題或關鍵字覆蓋不足

---

### 5. Core Web Vitals 和技術健康度
持續監控技術基礎是否健康。

**怎麼看：**
- GSC → 體驗 → Core Web Vitals
- GSC → 索引 → 頁面（監控錯誤和索引問題）

---

## 基礎 SEO 報告框架

### 改動當天先做 annotation

重大改動（改 title、模板、網址、外掛、修 bug）完成後，在 GSC Performance 圖表對日期按右鍵，加一條「做了什麼 + URL 群組」的 annotation。之後看到波動才能把時間線對起來。

- 每 property 最多 200 條、每條 120 字，500 天後自動刪除
- 所有 owner／full user 可見，不放個資
- comparison mode 與 24-hour view 不顯示

每月至少做一次這個快速檢查：

```
本月 SEO 月報

[流量]
- 自然搜尋點擊數：XXX（vs 上月 XXX，變化 +/-X%）
- 曝光數：XXX

[排名]
- 核心關鍵字排名：
  - [關鍵字 1]：第 X 名（vs 上月第 X 名）
  - [關鍵字 2]：第 X 名

[索引健康]
- 已索引頁面數：XXX
- 新增錯誤：XXX 個

[本月完成的 SEO 工作]
- [具體工作]

[下月計畫]
- [計畫]
```

## SEO ROI 的基礎計算概念

精確的 SEO ROI 計算很複雜，但這是基本概念：

```
SEO 帶來的價值 = 自然搜尋流量 × 轉換率 × 平均客單價

SEO 成本 = 人力投入（時間）+ 工具費用 + 內容製作費用

ROI = (SEO 帶來的收益 - SEO 成本) / SEO 成本× 100%
```

**現實面：**
- 很難精確歸因（用戶可能搜尋 → 離開 → 透過廣告回來購買）
- 可以用 GA4 的多管道歸因報告輔助理解
- SEO 的複利效果：投入的效益隨時間累積，不像廣告停止就沒有流量

## 如何向非 SEO 的人（老闆/客戶）說明 SEO 價值

**1. 用商業語言，不用技術詞彙**
不說：「我們的 DA 從 30 提升到 45」
說：「我們的網站在 Google 的影響力提升了，搜尋排名因此改善」

**2. 對比廣告成本**
「這個月自然搜尋帶來了 500 個點擊，如果用 Google Ads 買同樣流量，大約要花 XXXX 元」

**3. 展示趨勢，不是單點**
SEO 的效果是累積的，要展示 3-6 個月的趨勢圖，而不是單月數字。

**4. 設定可驗證期待**
不要給通用月份承諾。說清楚這次改動先看哪個領先訊號、什麼日期複查，以及什麼現象代表不是在等而是方向錯了。
