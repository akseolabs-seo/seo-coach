# 66 — 演算法更新共讀

**reason**：學員問「最近有沒有更新／我是不是被更新打到」時，把 Google 的公告、學員自己的資料與社群觀察分成三層讀，避免從一個更新名稱直接推出原因與修法。
**strip_when**：Google 不再公開排名更新紀錄，或 skill 不再處理流量變化診斷。

和 `46-core-update-timeline.md` 的分工：46 保留過期防護與歷史對照表；本檔是當下要走的程序，日期一律當場查，不靠記憶或 46 的表。公開來源規則照 `52-public-source-policy.md`。

## 三層證據怎麼說話

| 層 | 來源 | 可以說 | 不可以說 |
|---|---|---|---|
| 官方事實 | `updates` 指令或 Search Status Dashboard | 「Google 公布了 X 更新，[日期] 開始，[已完成／仍在推出]」 | 這次更新針對什麼（公告沒寫的部分）、你的網站被它影響 |
| 學員自己的資料 | `around`、面板總覽圖上的更新標記 | 「你的資源在更新開始前後各 N 天，點擊從 A 變成 B」 | 「所以是更新造成的」 |
| 社群觀察 `community observation` | 當下搜尋到的公開分析 | 「[誰] 用 [什麼資料] 觀察到 [什麼]，他們不知道 [什麼]」 | 當成 Google 的說法、當成這個站的原因、不標來源 |

只有第一層用事實語氣。第三層每一句都要帶來源與 `community observation` 標籤（對應 52 號檔的公開觀察或第三方估值）。

## 程序（一輪只走一步）

1. **官方事實**：執行 `node assets/gsc-tools/gsc.mjs updates`（不需要金鑰），或請學員開 https://status.search.google.com/ 。說出更新名稱、開始日、結束日；`end` 是空的就是仍在推出。學員的下降日早於所有近期更新時，直接說「日期沒有對上」，回到 `62-gsc-diagnosis-drills.md`。
2. **學員自己的資料**：已接 API 用 `around --site <p> --date <更新開始日>`，並看面板總覽圖的更新標記；沒接就請學員在 GSC 成效報表截同長度的前後兩段。前後必須等長。`complete: false`、後段不足，或更新還沒推完，都要明講「現在只能看到一半」。
3. **社群觀察**：**現在就搜尋**這一次更新的名稱加年月，不用記憶。讀 2–3 種不同性質的來源（例如新聞追蹤、資料廠商的統計、實務工作者的個案），每個只報四件事：誰、觀察到什麼、根據什麼資料、他們不知道什麼。搜不到可追溯的分析就說還沒有，不補。
4. **SEO Coach 的判讀**：把三層並排——哪裡一致、學員的資料哪裡和常見說法不一樣、現在還不能知道什麼。然後只選**一個**區分檢查，並說出推翻條件（「如果看到 ___，就不是更新這條線」）：

   | 想區分的事 | 檢查 |
   |---|---|
   | 是全站還是局部 | 下降是否集中在一種頁型或一個目錄（`query --dims page`，或面板的分組趨勢） |
   | 是哪一類需求 | 是否集中在一種查詢意圖；品牌詞與非品牌詞是否走向不同（面板的品牌詞分組） |
   | 是不是自己改的 | 同一段期間有沒有改版、搬家、改網址、robots／canonical 變動（變更筆記、學員回想） |
   | 是不是季節 | 比較方式切到「去年同期」，或 `summary --compare year` |

5. **決定**：通常是「等推出結束，[結束日 + 14 天] 用同一個指令重看」，或「做一項可回復的內容品質核對」（挑一個下降最多的頁面，回到 SERP 與頁面本身）。不從更新名稱列一串修法。把這一輪記成一則變更筆記或一張證據卡（→ `60-evidence-and-judgment-cards.md`）。

## 常見誤讀

- **推出期間的下降不是最終結果**：推出中排名會來回，完成後再看一次才算數。
- **更新名稱不是診斷**：「core update」只說明 Google 重新評估了排序，沒有說你的哪一頁、哪一點。
- **日期對上只是相關**：同一週也可能有季節、改版、追蹤或報表異常；對上只代表這條線值得查。
- **第三方「波動」工具是估值**：它們追蹤的是自己選的關鍵詞樣本，不是 Google 的資料，也不是這個站的資料。
- **沒有公告不代表沒有變動**：Google 只公告部分更新；此時仍照第 2、4 步從自己的資料查起，不發明一個未公告的更新當原因。
- **Discover 或垃圾內容更新不解釋一般網頁搜尋的所有下降**：先看公告寫的範圍。

## 回覆形狀

```markdown
官方（Google Search Status Dashboard，查核日）：
你的資料（資源、前後各 N 天、是否完整）：
community observation（來源 1／2／3：誰、看到什麼、根據什麼、不知道什麼）：
SEO Coach 的判讀：一致處／不一致處／還不能知道
一個區分檢查與推翻條件：
決定與回看日期：
```

新手一輪只給其中一段；四段都齊了才談決定。
