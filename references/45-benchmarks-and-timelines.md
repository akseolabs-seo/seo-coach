# 45 — CTR 基準值與修復生效時間表

用途：期待管理需要數據錨點時讀這份——耐心卡的「多久見效」、判斷「我的 CTR 正常嗎」、新站「這樣算慢嗎」。所有數字都是**概略參考值**，用來管理期待，不是承諾。

資料年份：2026 年初整理，數字屬長期穩定的量級參考。

---

## 排名位置 vs CTR 概略基準（自然結果）

| 位置 | 概略 CTR | 給用戶的白話 |
|------|----------|--------------|
| 第 1 名 | 25-30% | 第一名吃掉大盤 |
| 第 2-3 名 | 10-18% | 還在肉多的區域 |
| 第 4-5 名 | 5-8% | 首頁後段，標題好壞影響大 |
| 第 6-10 名 | 2-5% | 首頁尾巴——這裡是 title 改寫最划算的位置 |
| 第 11-20 名 | <1-2% | 第二頁形同隱形，但也是「最接近成功」的機會清單 |

使用注意：
- SERP 上方有廣告、地圖、AI 摘要時，全體 CTR 會被壓低——**跟自己比，不要跟表比**
- 判斷「CTR 差」的正確姿勢：同一站內，找「排名相近但 CTR 差很多」的頁面互相比
- 品牌字 CTR 天生高（50%+ 都正常），不要拿品牌字的 CTR 當整站標準

## 「低垂果實」判斷值

GSC 篩選：**排名 6-20 名 + 曝光 > 100/月** 的查詢 = 優先優化清單。這些字離首頁前段最近，改 title/內容的投報率最高。

## 修復生效時間表（耐心卡數據源）

| 動作 | 多久見效 | 什麼時候該懷疑不是在等、是有問題 |
|------|----------|----------------------------------|
| 提交 sitemap | 數天～數週 | 4 週後 GSC 仍「無法擷取」→ 檢查 sitemap 格式與位置 |
| 新頁面被收錄 | 數天～數週 | 4 週未收錄 → 查 noindex、內鏈孤島、內容太薄 |
| 移除誤設 noindex | 數天～數週 | 4 週後仍排除 → 用 URL 檢查工具看 Google 實際看到什麼 |
| 改寫 title/meta | 數天～2 週反映在 SERP | 3 週仍顯示舊的 → 看是否被 Google 自行改寫（代表你的版本不夠對題） |
| 修 robots.txt 誤擋 | 數天～數週恢復爬取 | 2 週後 GSC 仍大量「遭封鎖」→ 確認改的檔案真的上線了 |
| 301 轉址權重轉移 | 數週～數月 | — |
| 內容大幅改善 | 數週～數月 | 下次 Core Update 後仍無起色 → 回頭檢討內容方向 |
| Core Update 受影響後恢復 | 通常要等下一次 Core Update | 期間持續改善品質，不要亂動技術面 |
| 新站在競爭字有排名 | 3-6 個月起跳 | 8 週 `site:` 仍為 0 → 技術面有問題，不是沙盒 |

## 「正常的新手站」長什麼樣

給發文 3 個月內就焦慮的用戶：

- 前 1-2 個月：曝光緩慢爬升、點擊零星——**正常**
- 第 2-3 個月：長尾字開始有 11-20 名的排名——**正常且是好訊號**（進入低垂果實區）
- 拿自己跟經營三年的站比流量——**不公平也不必要**；比的應該是自己上個月

## 引用原則

- 對用戶說數字時永遠加「大概」「通常」「量級參考」
- 用戶問「為什麼我還沒到基準」→ 先回到診斷（是還在等，還是有結構問題），不用基準值審判用戶
