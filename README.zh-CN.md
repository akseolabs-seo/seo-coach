SEO Coach 是由 AK（[Threads @darkseoking](https://www.threads.com/@darkseoking)）设计的开源 AI 教练 Skill。

它不是 SEO audit、检查清单或问答知识库。它是一套以真实网站、能力证据和反复练习为核心的 SEO 学徒制：教练先示范一小步，陪你完成下一步，再逐渐撤掉提示，直到你能在陌生页面独立完成同一套判断。

## 我为什么做 SEO Coach

我一直认为，**SEO 是少数人的游戏**。

真正有用的 SEO，不只是“title 怎么写”“文章要多少字”这些公开知识，而是你怎样观察搜索结果、判断机会、在信息不足时做决定，以及失败后怎样找到原因。这些判断会直接形成竞争优势，所以市场上很少有老师会毫无保留地公开自己真正依赖的研究方法、客户经验和决策逻辑。

我做 SEO Coach，不是要假装一个免费的 Skill 能把你变成另一个我。

我想给你的是一个**低成本但正确的开始**：先把公开、可验证、值得新手掌握的基础练好；对 SEO 真正产生兴趣；在自己的网站排出第一个关键词；然后开始发展你自己的观察方式、思维逻辑和想法。

> 你用了 SEO Coach，不会因此变得跟我一样强。真正的差距仍然来自长期研究、实战、失败和判断。但它可以让你少走很多低级弯路，用更低的成本建立一个足够好的起点。

这也是 SEO Coach 和一般教学内容最大的不同：它不承诺把秘密交给你，而是陪你建立未来能够产生自己方法的基本能力。

## 学过 SEO，不等于会做 SEO

看过教程，不代表你会判断。拿到 audit，也不代表你知道下一步怎么做。

SEO Coach 会带你完成一条真实闭环：

```text
目标与安全
  → 修改前基准
  → 确认 Google 看得到
  → 理解查询、SERP 与承接页
  → 一项低风险、可还原的修改
  → 重新验证真实页面
  → 在正确时间回看数据
  → 决定保留、还原或再测试
  → 换陌生案例独立重做
```

进度不看“上完多少模块”，而看你能否在看过示范后、提示下、无提示时，以及延迟换题后继续完成任务。

## 它怎么教你

### 教练自主带路

你不需要先知道该选哪个模块、工具或报表。目标清楚时，教练会根据现有证据直接选择最小而有用的下一步，说明现在看哪里、为什么，以及怎样算完成。

每轮默认只教一个概念、推进一个检查，不会一开始就倒出整套 audit。

### 示范 → 共做 → 独立

新手不用猜答案。教练先示范第一个案例，陪你判断第二个，再把第三个交给你独立完成。你说“我不会”或“你先看”时，它会直接示范，不会继续盘问。

### 证据优先

教练会区分本轮真实观察、Google 官方说明、第三方估值、你授权的数据，以及尚未观察的部分。网站健康也是有效结果；它不会为了显得有价值而硬找问题。

### 修改后必须复验

修改前留底，修改后重新打开真实页面，并在合适的时间窗口回看 GSC／GA4。没有复验，就不宣称完成。

## 三条主要学习路线

### 从零到第一个可验证成果

在自己的网站完成目标、基准、索引证据、搜索机会、一项可逆修改、技术复验、延迟回看，以及陌生页面 Capstone。

最终得到的不是报告，而是一套你能重复执行的 SEO 工作方法。

### 搜索机会实验室

学习选题、关键词、搜索意图、内容缺口、网站架构、页面归属和 content brief。

主线是**手动判断**，不是工具操作——因为看不懂搜索结果的人，拿到 `KD = 23` 也不知道那代表什么。所以没有 Ahrefs、Semrush 或 DataForSEO 一样能完成完整训练：

1. 打开新的无痕／私人窗口，记录查询、地区、语言、设备和日期。
2. 教练示范第 1 个自然搜索结果。
3. 下一轮共同判断第 2 个。
4. 第 3 个由你独立判断。
5. 只有三条结果仍显示混合意图时，才再多看两条。
6. 证据不足时停在“暂时不能判断”，不强行得出结论。

竞品写了不代表你也该写；竞品没写也不自动等于机会。Content gap 还要核对真实需求、自站是否已经承接、你能否可信提供，以及它是否对业务有价值。

免费工具（关键词扩展、难度、SERP、排名查询、流量估算、AI 可见度）不会在第一轮丢给你，而是**按进度分层开放**：学会读画面之后，工具才作为**验证层**进场——你先讲你的判断，再打开工具对答案，不一致的地方就是最好的教学素材。所有工具数字一律标成第三方估值，不会冒充 Google 或 AI 平台的内部数据。

### 四篇 SEO 写作学徒制

这不是让 AI 代写四篇文章，而是通过四个逐渐提高难度的作品，把研究和写作判断交还给你：

- A1：教练示范与共做。
- A2：同型练习，减少提示。
- A3：更换搜索意图或页面类型。
- A4：无提示 Capstone。

每篇都保留 SERP 证据、brief、原稿、修改稿、反馈、QA、发布和观察记录。毕业看八项能力证据，不看 AI 总分。

## 你会实际学到什么

教练会根据你的网站和当前问题，按需调用技术、内容、链接和数据知识：

- 抓取、索引、robots.txt、sitemap、canonical、redirect、HTTPS 与基础结构化数据。
- title、H1、meta、URL、图片和页面承诺。
- GSC、GA4、修改前基准与修改后证据。
- 候选查询、搜索意图、SERP、内容缺口和页面映射。
- 内容质量、E-E-A-T、内链、旧内容判断和 SEO 写作。
- 流量下降、新站、改版、CMS 问题与常见 SEO 误区。
- Topical Map、SERP Features、AI 搜索、电商和本地 SEO 的基础判断。

18 个模块是教练的按需知识库，不是必须按顺序上完的课程表。

## 学习记录不会消失

经过你同意后，SEO Coach 可以维护：

- `seo-progress.md`：能力状态、错误、提示程度与 1／7／30 天复测。
- `seo-actions.md`：待办、完成证据与下一步。
- `seo-strategy-workbook.md`：查询、SERP、内容缺口、页面归属与 brief 练习。
- `seo-writing-portfolio.md`：四篇作品的版本与验收证据。
- `seo-ga4-log.md`：本轮真实看到的数据、基准与解释。

下次回来会从上次的能力缺口继续。没完成作业也不是继续学习的门票；教练会缩小任务或换一条仍然有效的路径。

- 有网站，但不知道先看哪里、改什么、怎么验证的人。
- 看过很多课程，却没有在真实网站完成过 SEO 闭环的人。
- 没有付费 SEO 工具，希望先学会手动研究的人。
- 想亲手完成 SEO 文章，而不是只收 AI 代写稿的人。

## 它不是什么

- 不是一键全站 audit 或健康分数生成器。
- 不是排名、流量或索引保证。
- 不是代写文章、代交策略或批量发布工具。
- 不会用固定 KD、字数、内链数量或插件分数替你下结论。
- 不会在缺乏证据时把猜测说成已经确认。

大型迁站、严重流量崩跌、大量掉索引、企业级国际 SEO、程序化建页，以及医疗、金融、法律等高风险判断，仍可能需要工程师或合格专业人员。

```text

https://github.com/akseolabs-seo/seo-coach
```

如果你的 AI Agent 有 GitHub 访问和本机文件权限，它可以自己完成下载、安装和验证。安装后打开一个新对话，直接说：

## 公开来源与隐私边界

SEO Coach 的所有教材，来自 **AK 整理、重新编排的公开资源**，以及我在 Threads 公开分享、能够通过公开 URL 核实的 SEO 理论和观点。公开资源包括 Google 官方文件、公开课程、公开网站／SERP，以及有明确授权或能够公开引用的资料。

它**不包含**我的私人研究方法、未公开测试、客户资料、客户案例细节、私信、未公开 prompt、私人 SOP 或其他本机项目。这条边界不是内容不足，而是刻意保护客户、研究资产与公开教学之间的界线。

因此，SEO Coach 提供的是扎实的公开基础和学习方法，而不是 AK 私人方法论的完整复制品。你仍然要依靠自己的网站、观察、实验和时间，发展出属于你的 SEO 判断。

每次构建公开分享版前，维护版本都会运行行为评测、路由测试、隐私泄漏 fixtures 和安装包一致性验证，用于检查它是否真的以教练方式带学，而不只是检查 Markdown 能否解析。维护者专用的 `evals/` 和 `scripts/` 不会混入公开安装包。

## 最后一句

SEO Coach 的目标不是替你做完 SEO，也不是让你背更多术语。

它要做的是：**在你旁边示范、陪你练习、纠正误判、保存证据，并逐渐撤掉支持，直到你不需要提示，也能在下一个陌生问题上做出可靠判断。**
